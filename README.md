# Pati Aşkı 🐾

Kedi temali, mobilde parmakla oynanan küçük bir oyun. Tek dosya, kurulum yok.

- `index.html` → oyunun tamamı
- `manifest.json` + ikonlar → telefonun ana ekranına eklenebilir (PWA)

Kişiselleştirme: `index.html` içindeki en üstteki `CONFIG` bloğu (isim, mektup, imza, seviye cümleleri).
